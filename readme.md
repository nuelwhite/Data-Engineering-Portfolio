# TMDB Movie Data Analysis using Python (Pandas) and APIs

## Project Overview

In this project, I built a ***movie data analysis*** pipeline using Python and Pandas. I extracted movie related data from an API (TMDB), performed transformations on the dataset, implemented key transformations, and loaded it to a dashboard.

--- 

### Project Objectives

* Extract data from API
* Data Cleaning and Transformation
* Exploratory Data Analysis on the data (EDA)
* Perform advanced filtering and ranking
* Franchise and Director Analysis
* Visualization and Insights
